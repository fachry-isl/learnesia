# Triage Labels

This project uses the default triage role labels.

## Canonical role mapping

- `needs-triage` -> `needs-triage`
- `needs-info` -> `needs-info`
- `ready-for-agent` -> `ready-for-agent`
- `ready-for-human` -> `ready-for-human`
- `wontfix` -> `wontfix`

## Usage guidance

When triaging:
- Apply exactly one primary workflow-state label at a time when possible.
- Reuse these labels rather than creating synonyms.
- Remove stale state labels when moving an issue to a new state.
